# Гостиница «Сладкие сны» — четыре отдельных задания

Каждое задание лежит в собственной папке и не требует запуска предыдущего.

1. `Задание_1_Диаграммы` — две UML-диаграммы, PNG и исходники.
2. `Задание_2_Прототип` — самостоятельные HTML/CSS/JS-макеты трёх страниц. Откройте `index.html`.
3. `Задание_3_Сайт` — рабочий PHP-сайт по требованиям задания 3, без специальных ограничений доступности периодов из задания 4.
4. `Задание_4_Финальная_версия` — полный вариант с ограничениями дат и проверкой пересечений одобренных броней.

Для заданий 3 и 4 требуется PHP 8.1+ с `pdo_sqlite`; в каждой папке свой README с инструкцией. Учетные данные администратора в этих двух версиях: `hotel123` / `adminHotel`.

**Примечание:** официальные ZIP-макеты `Прил_1_ОЗ_КИМ_09.02.09-2-2027.zip` и `Прил_2_ОЗ_КИМ_09.02.09-2-2027.zip` в исходных материалах отсутствовали. Поэтому во 2-м задании создан самостоятельный прототип, а не копия официальных макетов.
