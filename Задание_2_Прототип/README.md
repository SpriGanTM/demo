# Задание 2 — Прототип интерфейсов

Это самостоятельный статический прототип. Откройте `index.html` в браузере. Страницы: главная, каталог с демонстрационной фильтрацией и форма бронирования. Форма показывает демонстрационное сообщение и не сохраняет данные: полноценная серверная логика относится к заданию 3. Каталог содержит демонстрационные карточки, а не данные БД.
