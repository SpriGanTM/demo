# Задание 3 — Создание сайта

Самостоятельная реализация требований задания 3: PHP + PDO + SQLite, каталог номеров, серверная фильтрация, создание заявок, серверная валидация, информативные ошибки, базовая защита форм и панель модерации заявок.

**Границы задания 3:** здесь намеренно нет правила «заезд не раньше текущей даты» и запрета пересечения с одобренными бронированиями — эти доработки относятся к заданию 4. Валидация формата дат и условие «выезд позже заезда» сохранены.

## Запуск
Нужен PHP 8.1+ с `pdo_sqlite`. В терминале этой папки выполните `php -S localhost:8000`, затем откройте `http://localhost:8000`. База и демонстрационные номера создаются автоматически.

Администратор: `hotel123` / `adminHotel`.
