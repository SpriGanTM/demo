# Задание 4 — Финальная версия

Самостоятельная законченная версия сервиса. Включает каталог и серверную фильтрацию, бронирование с серверной проверкой дат (заезд не раньше текущей даты, выезд позже заезда), запрет пересечения с одобренными бронированиями, вход администратора и управление заявками (просмотр, одобрение, отклонение, удаление).

## Запуск
Нужен PHP 8.1+ с расширением `pdo_sqlite`. Выполните в этой папке `php -S localhost:8000` и откройте `http://localhost:8000`. SQLite-БД создаётся автоматически.

Администратор: `hotel123` / `adminHotel`.
